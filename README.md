# Калькулятор на Python с использованием Tkinter

## Описание

Данный скрипт создает простой графический калькулятор с использованием библиотеки Tkinter. Калькулятор позволяет выполнять базовые арифметические операции: сложение, вычитание, умножение, деление, а также вводить десятичные числа.

## Как работает код

1. **Импорт библиотек**  
   Импортируются модули `tkinter` для создания GUI и `messagebox` для вывода сообщений об ошибках.

2. **Функции**  
   - `click(symbol)` — добавляет нажатый символ (число или оператор) в поле ввода.  
   - `clear()` — очищает поле ввода.  
   - `calculate()` — вычисляет выражение, введенное в поле ввода, используя функцию `eval()`. Если происходит ошибка (например, деление на ноль или синтаксическая ошибка), выводится соответствующее сообщение.

3. **Создание окна приложения**  
   Создается основное окно с заголовком "Калькулятор", фиксированным размером 600x600 и запрещается изменение размеров окна.

4. **Поле ввода**  
   Создается поле ввода для отображения и ввода выражений и результатов. Поле выровнено по правому краю и имеет крупный шрифт.

5. **Кнопки калькулятора**  
   Создается набор кнопок с цифрами, операторами, кнопкой очистки и кнопкой вычисления результата.  
   - Кнопка `=` запускает вычисление выражения.  
   - Кнопка `C` очищает поле ввода.  
   - Остальные кнопки добавляют соответствующие символы в поле ввода.

6. **Размещение кнопок**  
   Все кнопки размещены с помощью менеджера геометрии `grid` в виде сетки.

7. **Запуск приложения**  
   Основной цикл Tkinter (`root.mainloop()`) запускается, ожидая действия пользователя.

## Использование

Для запуска калькулятора нужно выполнить скрипт на Python 3:

```bash
python calculator.py
